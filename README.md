# Superstore Sales Analysis Dashboard 📊

An interactive data analytics dashboard built using **Python, Pandas, Streamlit, and Plotly** to explore and analyze Superstore sales data. The dashboard provides dynamic filters, interactive visualizations, and downloadable reports to help understand sales performance, profitability, and business trends.

## 🚀 Features

- **Data Upload:** Supports CSV, TXT, XLSX, and XLS file formats.
- **Dynamic Filters:** Filter data by date range, region, state, and city.
- **Sales Analysis:** Analyze sales performance across different categories and regions.
- **Monthly Trends:** Explore monthly sales trends and performance.
- **Interactive Visualizations:** View treemaps, pie charts, scatter plots, and other interactive charts.
- **Profit Analysis:** Explore the relationship between sales, profit, and quantity.
- **Data Export:** Download filtered datasets and aggregated sales reports as CSV files.
- **Data Preview:** View the filtered dataset directly in the dashboard.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Pandas** – Data cleaning, manipulation, and analysis.
- **Streamlit** – Interactive web dashboard development.
- **Plotly Express** – Interactive data visualizations.
- **Plotly Figure Factory** – Additional visualization capabilities.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Superstore-Sales-Analysis-Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd Superstore-Sales-Analysis-Dashboard
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run dashboard.py
```

The dashboard will open in your default web browser.

## 📦 Requirements
